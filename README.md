# presentomb bloom

`presentomb bloom` is a reactive harmonic afterglow effect for vocals, guitars, synths, and pads.

It adds warmth, width, fracture, motion, and spectral memory while remaining mono-aware and responsive to incoming audio.

## Downloads

Download current builds from [GitHub Releases](https://github.com/presentomb3/presentomb-bloom/releases)

- Windows VST3
- Windows installer with optional standalone app
- Universal macOS VST3 for Apple Silicon and Intel
- Universal macOS standalone app for Apple Silicon and Intel


## Install

### Windows

Run the installer, or copy the VST3 bundle to:

```text
C:\Program Files\Common Files\VST3
```

### macOS

Copy the VST3 bundle to:

```text
~/Library/Audio/Plug-Ins/VST3
```

Move the standalone app to `Applications` if wanted.
